# TriNova Solutions LLP Website

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Final responsive behavior
- Desktop/laptop: five Solutions cards remain in one row.
- Tablet/mobile: cards stack only at the mobile breakpoint.
- Layout containers are fluid and do not use a narrow fixed desktop island.
- Hero artwork uses the supplied TriNova master logo without the previous white dummy logo card.
- About artwork uses the building scene with integrated branding; the UI header/footer use the supplied TriNova master logo.

## Important
`node_modules` is intentionally not included. Run `npm install` before starting the app.
